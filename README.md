## ✨ Функционал

### 🔐 Авторизация и безопасность
- Вход по логину и паролю (проверка через БД)
- Разграничение прав: `RoleID = 1` → администратор, остальные → обычный пользователь
- Капча-подтверждение: сборка изображения из 4 частей поворотом на 90°

### 🛠 Админ-панель (только для админов)
| Действие | Описание |
|----------|----------|
| ➕ Добавить | Создание новой записи в таблице `Cars` |
| ✏️ Изменить | Редактирование выбранной записи |
| 🗑️ Удалить | Удаление записи с подтверждением |
| 🔄 Обновить | Перезагрузка данных из БД |
| 🔍 Сортировка | По возрастанию/убыванию (клик по заголовку или кнопки) |
| 📊 Просмотр | `DataGrid` с автогенерацией колонок |

### 🚗 Таблица `Cars` (пример полей)
```
CarID (PK) | Brand | Model | Year | LicensePlate | Price
```

## 🚀 Установка и запуск

### 1️⃣ Требования
- Windows 10/11
- Visual Studio 2019 или новее
- .NET Framework 4.7.2 Developer Pack
- SQL Server Express LocalDB (устанавливается с VS)

### 2️⃣ Настройка базы данных
1. Откройте **SQL Server Object Explorer** в Visual Studio
2. Подключитесь к `(localdb)\MSSQLLocalDB`
3. Создайте базу данных `TestCarDb` (или восстановите из `.bak`, если есть)
4. Убедитесь, что таблицы `Users`, `Cars`, `Roles`, `UserPhones` существуют

### 3️⃣ Настройка подключения
В файле `App.config` проверьте строку подключения:
```xml
<connectionStrings>
  <add name="TestCarDbEntities" 
       connectionString="metadata=res://*/Data_.DataModel.csdl|...;
                         provider=System.Data.SqlClient;
                         provider connection string=&quot;
                           data source=(localdb)MSSQLLocalDB;
                           initial catalog=TestCarDb;
                           integrated security=True;
                           MultipleActiveResultSets=True;&quot;" 
       providerName="System.Data.EntityClient"/>
</connectionStrings>
```

### 4️⃣ Сборка и запуск
```
1. Откройте test1.sln в Visual Studio
2. Build → Rebuild Solution
3. Запустите через F5 или Ctrl+F5
```

> ⚠️ При первом запуске может потребоваться восстановление пакетов NuGet:  
> **Tools → NuGet Package Manager → Manage NuGet Packages for Solution → Restore**

## 🎮 Использование

### 🔹 Вход в систему
1. Запустите приложение → откроется окно авторизации
2. Введите логин и пароль (пример: `admin` / `admin123`)
3. Пройдите капчу: кликайте по изображениям, пока все не встанут ровно (0°)
4. Нажмите «Подтвердить»

### 🔹 Админ-панель
Доступна только пользователям с `RoleID = 1`:
- Просмотр списка автомобилей в таблице
- Добавление / редактирование / удаление записей
- Сортировка по колонкам (клик по заголовку)
- Кнопка «Обновить» для перезагрузки данных

### 🔹 Обычный пользователь
После входа видит только просмотр данных (кнопки редактирования скрыты).
